MINDSTASH MVP — FREE, SELF-CONTAINED

What's included:
- Mobile-responsive knowledge feed
- Topic filters and search
- Stash reader with key takeaways and a practical action
- Save/bookmark ideas
- Mark learned and simple progress/streak dashboard
- Local browser storage
- PWA manifest and service worker for install/offline caching

No API keys, paid services, or external libraries are required for this MVP.

Preview:
Open index.html in a modern browser. Some PWA features (service worker/install) require serving over HTTPS or localhost.

To install on iPhone:
1. Host this folder on a static HTTPS host (GitHub Pages is free).
2. Open the site in Safari.
3. Tap Share > Add to Home Screen.

Content currently uses a small curated sample library. The next development stage can expand the stash catalog and build daily briefings from chosen sources.
